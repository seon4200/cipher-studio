# Vibes: estilo editorial fotográfico sobre papel

Versión activa: `vibes-editorial-photographic-paper@2.0.0`.

El perfil guía fotografías editoriales verticales, contraste legible, recortes de papel, textura de impresión discreta y apoyos que expliquen la narración. Las referencias específicas se conservan dentro de cada proyecto y sólo aportan material, contraste, encuadre y jerarquía; el código no publica imágenes ni nombres de archivos de referencia.

El estilo de Animation es independiente y sigue siendo procedural para Visuales. En Vibes imagen→video, protagonista, fondo y cámara permanecen inmóviles. Sólo pueden moverse los apoyos gráficos especificados; se conserva la imagen elegida.
