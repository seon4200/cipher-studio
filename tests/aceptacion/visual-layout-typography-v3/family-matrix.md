# Matriz de familias históricas — V14

| Estructura | Estado | Certificada | Razón |
| --- | --- | --- | --- |
| constelacion | REQUIRES_SUPPORT | no | Its grammar is a central subject related to several real semantic nodes; one Hero plus text cannot materialize those nodes honestly. |
| marcoPoster | READY_MODERN | sí | A single Hero and a bounded text region fully materialize the poster grammar. |
| editorial | READY_MODERN | sí | Text is the first-class subject and no asset slot is required. |
| capasApiladas | REQUIRES_SUPPORT | no | Layering is only meaningful when two or more real layers or concepts exist. |
| redNodos | REQUIRES_MULTI_ASSET | no | A network needs multiple materialized nodes; generic dots would be false structure. |
| lineaTiempo | REQUIRES_SUPPORT | no | A timeline requires multiple ordered events, which SceneSpec V14 does not carry. |
| corteTransversal | REQUIRES_SUPPORT | no | The cross-section grammar requires multiple named strata. |
| partidoVertical | ADAPTABLE_HERO_TEXT | sí | One Hero and one text block can occupy opposite fields without placeholders. |
| cintaDiagonal | ADAPTABLE_HERO_TEXT | sí | The diagonal axis can relate one Hero to one text region. |
| anillosConcentricos | ADAPTABLE_SINGLE_HERO | sí | The rings express focus around one real Hero without inventing Support. |
| abanicoTarjetas | REQUIRES_MULTI_ASSET | no | A fan of cards requires several materialized cards or assets. |
| rayosImpacto | ADAPTABLE_SINGLE_HERO | sí | Impact geometry can subordinate itself to one Hero or to editorial text as subject. |
| engranajes | REQUIRES_MULTI_ASSET | no | Interlocking gears encode multiple interacting parts. |
| cuaderno | ADAPTABLE_HERO_TEXT | sí | A document field can contain one Hero and an adjacent annotation, or text alone. |
| cascada | REQUIRES_SUPPORT | no | A cascade requires an ordered series of distinct real items. |
| mundoIsometrico | REQUIRES_MULTI_ASSET | no | The world is built from several tiles or objects, not one repeated placeholder. |
| pilaVertical | REQUIRES_SUPPORT | no | A stack requires multiple real blocks or concepts. |
