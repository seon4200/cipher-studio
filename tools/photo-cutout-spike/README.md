# Photo cutout spike V15

This directory is an isolated feasibility harness, not a product dependency.
It accepts only already-local raster files and delegates output publication,
bindings, SceneSpec compilation, QC and rendering to the current V15 product
path. It does not contain a provider searcher, renderer, data-URI path, or
automatic production selector.

The runtime is intentionally external to the repository:

`C:\graphify\_spike-runtime\photo-cutout-v1`

The worker uses `REMBG_HOME` under that runtime so model binaries are not
written to a user cache. Its accepted models are deliberately limited to
`u2netp` and `isnet-general-use`; `bria-rmbg` is excluded pending commercial
licensing review.

The worker has five actions:

- `download`: measures only the model download into a fresh explicit cache.
- `load`: measures a cold `new_session` from an already-local model.
- `benchmark`: processes local source files at 512 and 1024 px and records
  cold/warm timings, deterministic SHA checks, alpha metrics and output paths.
- `quality-sheet`: composites source and both model outputs over black, white,
  and checkerboard backgrounds.
- `motion-sheet`: assembles existing V15 render frames without changing the
  renderer.

No artifact downloaded from Pixabay or generated by rembg is committed to Git.
The acceptance runner stores external-media evidence and provenance outside the
repository, with paths and SHA-256 values in its local JSON report.
