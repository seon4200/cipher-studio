# CIPHER Studio

Editor de vídeo de escritorio en Electron, TypeScript y React.
Genera vídeos narrados y reserva los Visuales para el motor gráfico propio.
El modo de fallo crítico es una degradación silenciosa con el log en verde.

Antes de tocar nada, lee completos `docs/COMO-SE-TRABAJA.md`, `docs/avance.md`,
`docs/plan-maestro.md`, `docs/puntos-retorno.md` y `docs/deuda-graficos.md`.
